# REGLA ESTRICTA DE PRIVACIDAD Y SEGURIDAD DEL USUARIO

- PROHIBIDO bajo cualquier circunstancia acceder, navegar, interactuar o consultar la pestaña o URL de pagos (`/settings/payments`, `/payouts`, o similar).
- PROHIBIDO solicitar, capturar, almacenar o utilizar datos bancarios, números de cuenta, IBAN, credenciales de PayPal o información financiera privada del usuario.
- Toda configuración de cobro, datos fiscales personales o vinculación de cuentas bancarias debe ser gestionada única y exclusivamente de forma manual por el usuario en su navegador privado.
