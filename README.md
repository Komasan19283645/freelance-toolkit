## 🇬🇧 English Summary & International Platform Suite

**Freelance Toolkit** is an open, privacy-first suite of lightweight web utilities engineered for independent professionals, consultants, and digital nomads worldwide.

### 🔒 Privacy-First & Zero-Friction Architecture
- **100% Client-Side**: Zero cookies, zero third-party tracking, zero server databases. All calculations and PDF generation execute locally in your browser.
- **Local Persistence**: Draft invoices automatically persist to browser `localStorage` so you never lose progress when switching tabs.
- **Instant Print-to-PDF**: Uses browser-native CSS print stylesheets optimized for standard letter and A4 documents with zero watermarks.

### 💱 Multi-Currency Engine
The entire toolset features native multi-currency selection with dynamic recalculations:
- **USD ($)**: United States Dollar (Default)
- **EUR (€)**: Euro
- **GBP (£)**: British Pound Sterling
- **CAD (CA$)**: Canadian Dollar
- **AUD (A$)**: Australian Dollar
